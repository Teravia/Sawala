## 3. Content Quality Classification

### A — High Value
- original research
- detailed guide
- verified experience
- high-quality answer
- useful data

### B — Useful
- relevant answer
- practical recommendation
- experience with sufficient context

### C — Normal
- ordinary discussion
- short but relevant response

### D — Low Effort
- one-word response
- generic agreement
- repeated content
- engagement bait

### E — Junk / Spam
- unrelated content
- promotional spam
- repeated posting
- automated spam

Only A/B/C can normally contribute to valid contribution counts.

---

## 4. Moderation Severity

### Level 0 — Normal
No action.

### Level 1 — Low
Warning / content correction.

### Level 2 — Moderate
Content removal / posting restriction.

### Level 3 — Serious
Thread lock / account restriction / moderation review.

### Level 4 — Critical
Immediate restriction and escalation for suspected serious illegal/safety content.

Automated detection may trigger Level 3/4 containment, but human review remains responsible for final platform action where appropriate.
